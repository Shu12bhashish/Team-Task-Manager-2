TEAM TASK MANAGER (FULL-STACK PROJECT)

## 📌 PROJECT OVERVIEW

This is a full-stack web application where users can:

* Create projects
* Add team members
* Assign tasks
* Track task progress

It includes authentication and role-based access (Admin / Member).

## 🚀 FEATURES

1. User Authentication (Signup/Login)
2. Role-Based Access Control (Admin / Member)
3. Project Management
4. Task Creation & Assignment
5. Task Status Tracking (Pending / In Progress / Completed)
6. Dashboard with task overview
7. Overdue task tracking

## 🛠 TECH STACK

Frontend:

* React.js (Vite)
* Axios

Backend:

* Node.js
* Express.js

Database:

* MongoDB (Mongoose)

Deployment:

* Railway

## ⚙️ HOW TO RUN LOCALLY

1. Clone the repository:
   git clone <your-repo-link>

2. Install backend dependencies:
   cd backend
   npm install

3. Install frontend dependencies:
   cd ../frontend
   npm install

4. Create a .env file in backend:
   MONGO_URI=your_mongodb_connection
   JWT_SECRET=your_secret

5. Run backend:
   cd backend
   node server.js

6. Run frontend:
   cd frontend
   npm run dev
